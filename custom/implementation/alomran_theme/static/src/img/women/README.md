# صور صفحة دورات السيدات (/women-courses)

الموديول فيه رسومات SVG جاهزة لكل صورة (ملفات .svg بهالمجلد).
لتبديل أي رسمة بصورة حقيقية: حط الصورة بنفس الاسم بصيغة webp أو jpg
وبتاخد الأولوية لحالها — بدون أي تعديل بالكود (الترتيب: webp ← jpg ← svg).

| الاسم      | وين بتظهر                          | المقاس المقترح |
|------------|------------------------------------|----------------|
| hero       | الهيرو (إذا ما في فيديو)           | 900×700        |
| fashion    | بطاقة تصميم الأزياء                | 800×520        |
| makeup     | بطاقة المكياج                      | 800×520        |
| jewelry    | بطاقة تصميم المجوهرات              | 800×520        |
| crochet    | بطاقة الكروشيه                     | 800×520        |
| drawing    | بطاقة الرسم                        | 800×520        |
| quote      | رسمة بطاقة "لأنكِ تستحقين..."      | 400×420        |
| form       | الصورة جنب الفورم (عليها النص)     | 700×800        |

static/src/video/women_hero.mp4 (+ women_hero_poster.webp)
