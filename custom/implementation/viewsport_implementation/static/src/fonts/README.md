# Report fonts

Bundled so the Viewsport reports render the same on every server (wkhtmltopdf only sees the
fonts installed on the machine that prints). All are free, open-licensed substitutes for the
Microsoft fonts used in the client's Excel templates:

| Family in the reports | File(s)                         | Replaces       | License            |
|-----------------------|---------------------------------|----------------|--------------------|
| VS Sans               | LiberationSans-*.ttf            | Arial          | SIL OFL 1.1        |
| VS Narrow             | LiberationSansNarrow-*.ttf      | Arial Narrow   | SIL OFL 1.1        |
| VS Arabic             | IBMPlexSansArabic-*.ttf         | Arial (Arabic) | SIL OFL 1.1        |
| VS Calibri            | Carlito-*.ttf                   | Calibri        | SIL OFL 1.1        |
| VS Cambria            | Caladea-*.ttf                   | Cambria        | Apache 2.0         |
| VS Georgia            | Gelasio-*.ttf                   | Georgia        | SIL OFL 1.1        |
| VS Script             | DancingScript-Bold.ttf          | Segoe Script   | SIL OFL 1.1        |

Carlito, Caladea, Gelasio, IBM Plex Sans Arabic and Dancing Script come from Google Fonts
(fonts.google.com); Liberation fonts from the Liberation project.
